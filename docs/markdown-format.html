Markdown 格式

当前侧栏「复制 Markdown」所用的格式。本页不改变输出。

使用手册Privacy / 隐私政策

侧栏只在有正文时复制。正文是：摘要去掉首尾空白后还有字符，或者至少有一条划线。标题和 URL 不算正文。两者都没有时，按钮禁用，不写剪贴板，也不显示「已复制 ✓」。

The side panel copies only when there is body text: the summary is non-empty after trim, or there is at least one highlight. The title and URL are not body text. Otherwise the button stays disabled, nothing is written to the clipboard, and the control does not show success.

下面的示例是复制成功时剪贴板里的完整字符串，包含末尾换行。中文界面用中文小标题，英文界面只更换这四个标签，结构相同。

  • 中文：来源：、摘要、划线、评论：
  • English: Source: (with a trailing space), Summary, Highlights, Note: (with a trailing space)

不转义

标题、URL、摘要、划线、评论都按原字符写入。#、*、_、[文字](网址)、> 都不会加反斜杠。

划线里的换行拆成多行，每一行前面加 > （大于号加一个空格）。空行也是 > 。摘要和评论里的换行保持原样，不会变成引用。

评论先去掉首尾空白。去掉之后如果是空的，整行评论省略。评论中间的换行留在同一条评论里。

示例里的日期只是示例，例如 2026-11-13 和 2026-10-15。实际复制时，日期是复制当时的本地日历日，格式为 YYYY-MM-DD。URL 是这条笔记的页面键。

转义、换行、标题、URL、引用、评论、摘要

# 标题 *不是* 转义
来源：https://example.com/a?q=1 · 2026-11-13
## 摘要
摘要第一行
摘要第二行，保留 *星号* 与 [链接](https://example.com)。
## 划线
> 第一行
> 
> 第三行 > 原样
> 引用
评论：评论一行
评论第二行

对应输入：标题 标题 *不是* 转义；摘要两行，第二行含 *星号* 和 [链接](https://example.com)。；第一条划线是 第一行、空行、第三行 > 原样，评论只有空白，所以没有评论行；第二条划线是 引用，评论是 评论一行 换行 评论第二行。

只有摘要

划线数组为空时，划线小标题仍在，下面没有引用。

# Only summary
来源：https://example.com/s · 2026-11-13
## 摘要
正文摘要
## 划线

只有划线

摘要为空时，摘要小标题仍在，下一行是空行，然后才是划线。

# Only highlight
来源：https://example.com/h · 2026-11-13
## 摘要

## 划线
> 仅划线

空态

没有记录，或者有记录但划线为 0 且摘要去掉首尾空白后为空（包括纯空白摘要）：侧栏不复制。标题和 URL 不算正文。因此剪贴板里不会出现「只有标题、来源和两个空章节」的文档。空正文是按钮禁用，不是另一份 Markdown。复制成功的样本以上面四段为准。
